# Validation Debt

## Purpose
This file tracks known, unresolved validation debt for the repository.

## Rules
- record only active issues that are not being fixed in the current task
- keep entries concrete and project-specific

## Entries
- no active validation debt recorded for this onboarding pass

## Update format
- date: use the ISO date when a debt entry is opened
- scope: repository or task
- issue: concise issue statement
- owner: responsible owner
- status: open or resolved
